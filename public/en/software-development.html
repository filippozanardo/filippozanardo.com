Software development

I build web applications and custom software.

I build features and products for everyday use. I can start from a business requirement or an application already in production.

What I can build or improve

  • PHP and Laravel applications

    When a product needs custom functionality, I design and build the application logic, user workflows and integrations with your existing systems.

  • Admin panels with FilamentPHP

    When data is hard to manage or teams repeat tasks by hand, I build Laravel admin panels with roles, permissions, filters and custom workflows.

  • WordPress and WooCommerce

    When standard themes and plugins fall short of your publishing or sales workflow, I build the themes, extensions and integrations you need.

  • Business applications

    I turn spreadsheets and manual handoffs into applications that collect data, assign responsibilities and make work trackable.

  • SaaS products

    I build the components needed to serve multiple customers, from data isolation to accounts, subscriptions and administration.

  • APIs and integrations

    I connect applications and external services to reduce manual entry and handle data exchange, failures and retries.

  • AI and process automation

    I build AI features and integrate them into business applications. These include extracting and classifying information, processing documents, searching content and building assistants that help users with everyday tasks.

    I connect these features to existing data, APIs and application workflows, with checks and human oversight where needed.

  • Maintenance and modernisation

    I upgrade PHP, Laravel and dependencies, resolve issues and plan incremental improvements around the people already using the software.
